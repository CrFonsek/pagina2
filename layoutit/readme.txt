1. DESCRIPCIÓN DEL PROYECTO
---------------------------
Este proyecto es una página web informativa sobre la Selección Colombia de Fútbol. 
Incluye su historia, logros destacados (como la Copa América 2001 y el Mundial 2014), 
un carrusel de imágenes, un formulario de registro y enlaces a redes sociales.


2. TECNOLOGÍAS UTILIZADAS
-------------------------
- HTML5: Para la estructura y contenido del sitio web.
- CSS3: Para los estilos visuales, animaciones y uso de variables de color.
- Bootstrap 5: Para el diseño adaptativo (celular, tablet y PC) y componentes como la barra de navegación y el carrusel.
- Bootstrap Icons: Para los íconos de la página.


3. ARCHIVOS DEL PROYECTO
------------------------
- index.html: La página principal.
- stile.css: Mis estilos personalizados con los colores de Colombia.
- bootstrap.min.css y bootstrap.bundle.min.js: Archivos de Bootstrap para el diseño y funciones.
- Carpeta "img": Contiene las fotos de la página y el video de fondo (videofondo.mp4).


4. INSTRUCCIONES DE EJECUCIÓN
-----------------------------
1. Descargar o descomprimir la carpeta del proyecto.
2. Asegurarse de mantener todos los archivos y la carpeta "img" juntos en la misma ruta.
3. Dar doble clic sobre el archivo "index.html" para abrirlo en cualquier navegador (Chrome, Edge, Firefox).


5. CARACTERÍSTICAS PRINCIPALES
------------------------------
- Video de fondo con capa transparente para mejorar la lectura.
- Barra de navegación superior fija con diseño azul y amarillo.
- Carrusel de imágenes automático.
- Formulario de registro para el usuario.
- Tarjeta animada de logros con efecto al pasar el mouse.
- Indicador en pantalla que detecta si estás en celular, tablet o computador.
